# 일반마법사 커리큘럼 · 결투 연습

화염·냉기·전격·밀기·당김·장막 중 세 종류를 Q·W·E에 배치해 조합하는 쿼터뷰 3D 브라우저 게임입니다. 현재 상대는 AI이며 온라인 대전과 레벨업은 구현하지 않았습니다. 모든 조합은 처음부터 사용할 수 있습니다.

## 실행

Python 3이 설치된 환경에서 이 폴더를 터미널로 연 뒤 실행합니다.

```sh
python3 -m http.server 8873 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:8873 에 접속합니다. 해당 포트가 사용 중이면 다른 번호를 사용하세요. HTML 파일을 직접 여는 방식은 모듈 보안 정책 때문에 지원하지 않습니다.

## 1륜 선택

시작 화면에서 Q·W·E 칸을 누른 뒤 마법을 고릅니다. 이미 다른 칸에 배치된 마법을 고르면 서로 교환합니다. 선택한 세 종류만 조합할 수 있으며 배치는 현재 브라우저에 저장됩니다. 경기 중 상단의 마법 선택으로 바꿀 수 있고, 적용하면 새 결투가 시작됩니다. 취소하면 이전 경기로 돌아갑니다.

신규 계열은 공통 조합 규칙으로 동작합니다. 냉기는 감속, 전격은 빠른 투사체와 추가 방전, 당김은 견인과 흡인 구역을 사용합니다. 모든 조합의 밸런스가 검증된 완성판은 아닙니다.

## 조작

- 우클릭: 이동. 마우스 위치로 조준합니다.
- Q / W / E: 짧게 눌렀다 떼면 즉발. 계속 누르면 원 하나당 1.2초씩 충전합니다.
- 첫 원 충전 중 다른 키를 누르면 현재 원을 완성한 다음 새 재료를 사용합니다.
- 여러 키가 눌려 있으면 가장 최근에 누른 키가 다음 재료입니다.
- Q를 유지한 채 W를 누르고 계속 유지하면 QWW입니다.
- 두 번째 W 원 충전 중 W만 떼고 Q를 유지하면 QWQ입니다.
- 모든 키를 떼면 발사합니다. 미완성인 마지막 원은 위력만 더합니다.
- Space: 마우스 방향으로 3.6m 구릅니다. 재사용 2.4초, 구르기 시작 후 0.28초 동안 피해를 피합니다. 충전은 구르기 동안 잠시 멈추고 이어집니다.
- AI는 이동 예측 사격, 삼중탄, 근거리 냉기 폭발, 투사체 회피와 제한적인 방어를 사용합니다.
- 최대 세 원까지 쌓입니다. Esc는 주문 취소, P는 일시정지입니다.
- 오른쪽 위 조합 안내에서 원 수와 첫 입력을 고르면 주문 이름과 실제 효과를 볼 수 있습니다.
- 대결 모드 버튼을 누르면 연습 모드로, 다시 누르면 대결 모드로 바뀝니다. 전환하면 경기 상태를 초기화합니다.
- 연습 모드는 상대가 공격하지 않고 마력이 소모되지 않습니다. 상대 체력이 0이 되면 회복하며 승패를 기록하지 않습니다.

## 검증

`node test.mjs`로 짧은 입력, QWW/QWQ 분기, 반복 키 입력, 미완성 원, 최대 세 원, 취소, 주문 이름을 검사합니다.

Three.js 0.169.0을 함께 제공합니다. 라이선스는 dist/THREE-LICENSE.txt에 있습니다. 기본 모델과 맵은 코드로 생성합니다.
