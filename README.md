# 일반마법사 커리큘럼 · 결투 연습

화염·냉기·전격·밀기·당김·장벽 중 세 종류를 Q·W·E에 배치해 조합하는 쿼터뷰 3D 브라우저 게임입니다. AI 연습과 방 코드로 접속하는 온라인 1대1 대전을 지원합니다. 몬스터를 사냥해 레벨을 올리고, 스킬 포인트로 선택한 1륜을 배우거나 강화합니다.

## 실행

Python 3이 설치된 환경에서 이 폴더를 터미널로 연 뒤 실행합니다.

```sh
python3 -m http.server 8873 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:8873 에 접속합니다. 해당 포트가 사용 중이면 다른 번호를 사용하세요. HTML 파일을 직접 여는 방식은 모듈 보안 정책 때문에 지원하지 않습니다.

## 1륜 선택

시작 화면에서 Q·W·E 칸을 누른 뒤 마법을 고릅니다. 이미 다른 칸에 배치된 마법을 고르면 서로 교환합니다. 선택한 세 종류만 조합할 수 있으며 배치는 현재 브라우저에 저장됩니다. 경기 중 상단의 마법 선택으로 바꿀 수 있고, 적용하면 새 결투가 시작됩니다. 취소하면 이전 경기로 돌아갑니다.

신규 계열은 공통 조합 규칙으로 동작합니다. 빙결은 감속, 전격은 낙뢰, 당김은 끌어오는 충격파를 사용합니다. 모든 조합의 밸런스가 검증된 완성판은 아닙니다.

## 조작

- 우클릭: 이동. 마우스 위치로 조준합니다.
- Q / W / E: 짧게 눌렀다 떼면 즉발. 계속 누르면 원 하나당 1.2초씩 충전합니다.
- 첫 원 충전 중 다른 키를 누르면 현재 원을 완성한 다음 새 재료를 사용합니다.
- 여러 키가 눌려 있으면 가장 최근에 누른 키가 다음 재료입니다.
- Q를 유지한 채 W를 누르고 계속 유지하면 QWW입니다.
- 두 번째 W 원 충전 중 W만 떼고 Q를 유지하면 QWQ입니다.
- 모든 키를 떼면 발사합니다. 미완성인 마지막 원은 위력만 더합니다.
- Space: 마우스 방향으로 3.6m 구릅니다. 재사용 2.4초, 구르기 시작 후 0.28초 동안 피해를 피합니다. 충전은 구르기 동안 잠시 멈추고 이어집니다.
- 상대도 매 경기 서로 다른 1륜 세 개를 고르고, 그 재료만 조합합니다. 원당 1.2초, 최대 세 원이며 플레이어와 같은 주문 효과와 마력 비용을 사용합니다.
- 상대가 고른 재료는 체력바 아래, 충전 순서는 머리 위 원에 표시합니다. 전방 공격은 발사 직전 0.35초 동안 방향을 고정합니다. 전격은 범위 밖으로 이동하거나 구르기로 피할 수 있습니다.
- 최대 세 원까지 쌓입니다. Esc는 주문 취소, P는 일시정지입니다.
- 오른쪽 위 조합 안내에서 원 수와 첫 입력을 고르면 주문 이름과 실제 효과를 볼 수 있습니다.
- 대결 모드 버튼을 누르면 연습 모드로, 다시 누르면 대결 모드로 바뀝니다. 전환하면 경기 상태를 초기화합니다.
- 연습 모드는 상대가 공격하지 않고 마력이 소모되지 않습니다. 상대 체력이 0이 되면 회복하며 승패를 기록하지 않습니다.

## 화염·빙결·전격

첫 재료가 화염·빙결·전격이면 해당 형태로 발동합니다. 완성한 원이 1/2/3개일 때 사거리는 2.5/4.1/5.7m입니다. 미완성 원은 사거리를 늘리지 않습니다.

- 화염: 전방 분사, 낮은 직접 피해, 2초 화상(0.5초마다 2 피해). 몸이 붉어집니다.
- 빙결: 전방 얼음 분사. 지속 피해 없이 1.5/2/2.5초간 이동 속도를 45% 낮춥니다. 몸이 푸르게 변합니다.
- 전격: 범위 안의 적에게 즉시 낙뢰. 적이 없으면 범위 안의 임의 지점에 떨어집니다. 원이 늘면 벼락이 굵고 커집니다.
- 뒤에 밀기·당김·장벽을 섞으면 밀침·끌어당김·보호막이 추가됩니다. 화염/빙결 뒤의 전격은 머리 위에서 떨어지는 공격으로 바꿉니다.
- 화상과 감속이 겹치면 붉은색과 푸른색 표시가 번갈아 나타납니다.

## 밀기·당김·장벽

- 밀기와 당김은 전방 부채꼴 충격파입니다. 완성한 원 1/2/3개에 따라 범위가 3/4.5/6m, 이동시키는 거리가 최대 1.2/2.1/3m로 늘어납니다. 장애물을 넘지 않으며, 당김은 시전자 앞에서 멈춥니다.
- 장벽은 마우스로 조준한 위치(최대 6m)에 설치됩니다. 벽이 있으면 벽 앞에 설치하며, 시전 방향을 기준으로 가로로 섭니다. 설치 후 위치와 방향이 고정됩니다.
- 장벽의 내구도는 24/48/72, 유지 시간은 3/5/7초입니다. 적 투사체를 막고 내구도를 소모합니다. 바닥 범위 공격은 막지 않습니다. 동시에 하나만 설치하며 다시 쓰면 교체합니다.

## 상대 공격 범위 표시

상대가 화염·빙결을 충전하면 최종 주문의 부채꼴 범위를 바닥에 표시합니다. 장애물 뒤는 표시에서 제외합니다. 마지막 0.35초에는 방향과 위치를 고정합니다.
전격은 시전자 중심의 원형 사거리를 표시합니다. 발동 순간 원 안에 있으면 낙뢰가 떨어집니다. 원 밖으로 이동하거나 구르면 피할 수 있습니다. 발사·모드 전환·경기 종료 시 표시는 사라집니다.

밀기·당김 피격 시 약 0.3~0.5초 동안 감속하며 이동하고, 몸이 이동 방향으로 기울었다가 복귀합니다. 장애물에 닿으면 이동을 멈춥니다. 플레이어와 상대에 동일하게 적용하며, 구르기를 시작하면 남은 강제 이동을 해제합니다.

## 마법 효과

캐릭터와 경기장은 3D이며, 스킬은 PVFX Foundry의 투명 PNG 애니메이션으로 표시합니다. 화염·빙결 분사, 마법탄, 낙뢰·낙하, 밀기·당김, 장벽, 보호막, 피격·파괴 효과를 2D로 교체했습니다. 장벽 이미지는 실제 벽 방향에 맞춘 평면에 표시하고 마법탄은 이동 방향을 따라 회전합니다. 공격 범위와 충돌 판정은 별도로 유지합니다.

동시 효과는 최대 64개이며, 프레임 시간과 기준점은 원본 메타데이터를 따릅니다. 효과 종료·주체 삭제·재시작 때 자원을 정리합니다. `test-pixel-vfx.mjs`는 독립 재생, 평면 장벽, 이동 추적, 수명과 정리를 검사합니다.

## 원형 낙뢰와 속성 장벽
낙뢰 표시는 시전자 중심의 원형 사거리입니다. 발동 순간 원 안의 적에게 벼락이 떨어집니다. 적이 없으면 원 안 임의 지점에 떨어집니다.
장벽은 시전자와 상대 모두의 이동·구르기·강제 이동을 막습니다. 장벽 뒤에 섞은 재료는 벽의 색 띠와 접촉 효과가 됩니다. 벽 1m 이내의 적에게 0.8초 간격으로 화상·감속·전격 피해·밀어내기·당김을 적용합니다. 장벽 주인에게는 속성 피해를 주지 않습니다.

## 마법 조합도
`/skill-tree.html`에서 일곱 기본 마법별 조합 경로를 봅니다. 두 재료 가지를 선택하면 세 번째 재료의 일곱 분기가 나타납니다. 상세 설명과 수치는 게임의 주문 모듈에서 읽으며, 현재 브라우저에서 선택한 세 마법만 보는 필터와 조합별 링크 복사를 제공합니다.

## 몬스터 사냥과 성장

맵은 120×120m 면소재지입니다. 카메라는 플레이어를 따라가며 미니맵에 자신·상대·몬스터를 표시합니다. 세 종류의 몬스터가 무작위 위치에 5초마다 추가되며, 최대 12마리까지 유지됩니다. 초기에는 양쪽 시작 지점 주변을 포함해 여덟 마리를 배치합니다. 몬스터는 공격받거나 3.2m 이내로 접근하면 반격합니다. 화염·빙결·충격파·속성 장벽은 여러 몬스터를 공격할 수 있습니다. 낙뢰는 범위 안에서 마우스 위치와 가장 가까운 대상 하나를 공격합니다.

- 처음 선택한 세 마법 중 Q부터 확인해 장벽이 아닌 첫 마법 하나를 배운 상태로 시작합니다.
- 플레이어가 처치한 몬스터만 경험치 20/25/30을 줍니다. 화상·추가 방전·장벽으로 처치해도 인정합니다. 시간 경과나 상대 마법사 처치는 경험치를 주지 않습니다.
- 레벨업마다 스킬 포인트 1을 받습니다. 2레벨에 필요한 경험치는 40이며 이후 20씩 늘어납니다. 최대 9레벨입니다.
- 왼쪽 성장 창에서 포인트 1로 새 1륜을 배우거나, 배운 마법을 숙련 3까지 강화합니다. 배우지 않은 키는 시전과 조합 모두 사용할 수 없습니다.
- 숙련 2/3은 그 마법으로 시작하는 주문의 직접 피해를 15/30% 높입니다. 장벽은 피해 대신 내구도를 높입니다. 숙련도는 충전하는 원 수와 별개입니다.
- 처치하면 마력 10, 레벨업하면 체력 20을 회복합니다.
- 새 대결·마법 변경·모드 전환은 성장과 몬스터를 초기화합니다. 성장 정보는 경기 안에서만 유지됩니다. 상대 마법사도 같은 성장 규칙으로 사냥하고 마법을 배웁니다.

`node test-progression.mjs`로 경험치 이월, 포인트 소비, 시작 마법, 숙련 및 레벨 상한을 검사합니다.

## 상대 성장과 낙하 조합

상대도 공격 가능한 1륜 하나로 시작합니다. 자신이 처치한 몬스터의 경험치만 받고, 플레이어와 같은 레벨·경험치·포인트·숙련도 규칙을 사용합니다. 받은 포인트로 미습득 공격 마법, 장벽 순으로 배운 뒤 숙련도를 올립니다. 머리 위에 레벨·사냥 수와 습득 상태를 표시합니다. 평소에는 몬스터를 사냥하고, 플레이어가 3.5m 안에 들어오거나 공격하면 대결합니다. 몬스터는 양쪽 마법사에게 반격합니다.

화염·빙결·밀기·당김 뒤의 어느 자리에든 전격을 넣으면 머리 위 낙하 공격으로 바뀝니다. 첫 재료의 색과 화상·감속·밀침·끌어당김을 유지하며, 기존 추가 방전 효과는 낙하 방식으로 대체합니다. 시전 순간 범위 안에서 조준 위치와 가까운 대상을 고르고, 해당 지점에 0.28초 뒤 떨어집니다. 작은 적중 원 밖으로 이동하거나 구르면 피할 수 있습니다. 대상이 없으면 사거리 안 임의 지점에 떨어집니다. 전격으로 시작하면 기존 낙뢰이고, 장벽 뒤 전격은 기존 낙뢰 장벽입니다. 게임의 바닥 예고와 조합도 애니메이션·설명도 동일한 규칙을 사용합니다.

`node test-enemy-growth.mjs`는 미습득 마법 사용 방지, 자동 포인트 소비, 낙하 순서와 상태 효과 보존을 검사합니다. `node test-vfx.mjs`는 네 계열 낙하 색·이동·자원 정리도 확인합니다.

## 밀기를 이용한 발사

화염·빙결·전격 뒤에 밀기를 넣으면 조준 방향으로 구체를 발사합니다. 첫 속성의 개수는 크기·직접 피해·폭발 범위를, 밀기의 개수는 속도와 사거리를 늘립니다. 속성＋밀기에 들어간 밀기는 적을 미는 효과 대신 발사 방식으로 쓰입니다. 밀기로 시작하는 주문은 기존 전방 충격파입니다.

| 조합 | 지름 | 속도 | 사거리 | 폭발 반경 |
|---|---:|---:|---:|---:|
| 화염＋밀기 | 0.64m | 9m/s | 8m | 0.9m |
| 화염＋화염＋밀기 | 1.2m | 6m/s | 8m | 2.1m |
| 화염＋밀기＋밀기 | 0.44m | 16m/s | 12m | 0.55m |

큰 화염구는 직접 피해 배율 1.7, 2.5초간 0.5초마다 화상 피해 3을 줍니다. 기본·고속 화염구는 2초간 0.5초마다 화상 피해 2를 줍니다. 충전 위력·숙련 배율은 별도로 적용됩니다. 빙결은 얼음구와 감속, 전격은 전기구를 사용합니다. 적·장애물에 닿거나 사거리 끝에 도달하면 한 번 폭발하며, 폭발도 장애물을 관통하지 않습니다. 적 장벽에 닿으면 장벽 내구도를 깎고 사라집니다. 빠른 구체는 이동 구간 전체로 충돌을 검사합니다.

화염＋밀기＋당김은 맞은 적을 시전자 방향으로 끌어오는 화염구입니다. 전격이 뒤에도 들어간 화염＋밀기＋전격은 기존 낙하 방식이 우선합니다.

장벽＋밀기는 캐릭터 앞에서 전진하는 장벽입니다. 속도 2m/s, 이동 거리 6m이며, 장벽＋밀기＋밀기는 4m/s·9m입니다. 장벽＋장벽＋밀기는 내구도 72·7초, 장벽＋밀기＋밀기는 내구도 48·5초입니다. 장벽은 닿은 캐릭터를 조금씩 밀고, 장애물이나 밀 수 없는 대상 앞에서는 멈춥니다. 이동을 마치면 남은 시간 동안 그 자리에 유지됩니다.

`node test-projectiles.mjs`는 구체 종류별 차이, 입력 순서, 이동 구간 충돌, 당김 효과, 장벽의 밀기·정지·최대 이동 거리를 검사합니다. 조합도와 미리보기는 같은 수치를 읽습니다.

## 장벽·장판 및 2D 미리보기 (2026-11-06)

기존 장벽의 내부 ID `e`를 유지해 저장된 마법 배치와 링크가 이어집니다. 새 `t`는 장판입니다. 장판이 포함되면 바닥 설치가 우선합니다. 기본 반경 1.6m, 설치 거리 6m, 유지 4초이며 0.5초마다 범위 안의 적에게 효과를 줍니다. 장판을 더 넣으면 반경 0.6m·유지 2초가 추가되고, 장벽을 섞으면 유지 2초가 추가됩니다. 장벽과 장판은 각각 시전자당 하나씩 유지합니다. 장판은 이동·투사체를 막지 않으며 지형을 넘어 피해를 주지 않습니다.

장판 기본 피해는 회당 2, 화염 3, 전격 5, 빙결 1이며 숙련 배율을 적용합니다. 화염은 화상, 빙결은 감속, 전격은 반복 방전, 밀기·당김은 중심 기준 강제 이동을 더합니다. 화염·전격이 함께 있으면 기본 피해는 화염 기준이며 방전 효과가 함께 표시됩니다.

조합도는 7개 기본 마법, 49개 두 재료 조합, 343개 세 재료 조합을 표시합니다. 모든 조합에 게임과 같은 PNG 에셋을 사용하는 Canvas 애니메이션이 있습니다. 재생·일시정지·다시 재생·재생 위치 이동·크게 보기를 지원합니다. 별도 MP4 파일이 아닌 실시간 미리보기이며 캐릭터와 배경은 설명용 그림입니다.

`dist/assets/pvfx/`의 출처는 https://nerijs.itch.io/pvfx-foundry 이며 원본 PNG와 메타데이터는 CC0 1.0입니다. 라이선스와 출처를 동봉했습니다. 다운로드한 전체 원본은 배포하지 않습니다.

검증: 기존 주문·성장·상대·투사체 테스트, `test-ground.mjs`, `test-pixel-vfx.mjs` 통과. 브라우저에서 실제 전투 399개 주문을 실행하고 재시작 후 장벽·장판·마법탄·효과가 모두 비워지는 것을 확인했습니다. 조합도 399개 미리보기의 네 재생 시점에서 스크립트 오류가 없었습니다. 장판·장벽 화면과 미리보기 재생·확대를 확인했습니다.


## 3D 동작을 따르는 2D 캐릭터 (2026-11-06)

게임 캐릭터는 3D 관절의 키프레임 동작을 평면 색 몸체로 표시합니다. 기본 걷기는 직접 만든 AnimationClip이며 외부 모션 캡처 에셋은 아닙니다. 시전과 구르기는 게임 상태에 따른 자세 보정입니다.

`character-lab.html`에서 GLB, 자체 포함 glTF, BVH를 불러와 2D 결과를 확인합니다. Mixamo 관절 이름을 자동 연결하며 다른 뼈대는 관절 직접 연결에서 지정할 수 있습니다. 여러 클립 선택, 재생 속도, 방향, 카메라 높이를 지원합니다. 외부 텍스처·bin 파일이 필요한 glTF와 압축 확장용 디코더는 지원하지 않습니다. 미리보기에서 불러온 파일은 저장하거나 게임에 자동 적용하지 않습니다.

Three.js 0.169.0 공식 GLTFLoader, BVHLoader, BufferGeometryUtils를 vendor에 동봉했습니다. 라이선스는 dist/THREE-LICENSE.txt를 따릅니다. Bonebase 확장 자체를 포함한 것이 아니라 설명된 동작 변환 원리를 별도로 구현했습니다.

`node test-motion-import.mjs`: BVH·자체 포함 glTF 입력, 관절 연결과 실제 동작 변화, 잘못된 파일 안내를 검사합니다. `node test-wizard.mjs`: 색 구분, 자세 변화, 16방향에서 평면 몸체의 카메라 정렬을 검사합니다.

동작 확인 화면에 베기·주먹 타격·방어·마법 시전 키프레임 클립을 추가했습니다. 각 동작 버튼은 기본 뼈대로 돌아가 해당 동작을 반복 재생합니다. 재생 위치 슬라이더로 정지 자세를 확인할 수 있습니다. 이번 클립은 확인 화면에서 선택하며, 게임의 공격 판정에는 새 동작을 연결하지 않았습니다.

마법 시전 자세를 분리했습니다. 짧은 입력은 오른손을 뒤로, 왼손을 오른쪽 어깨에 둔 준비 자세 후 12fps 기준 세 번째 프레임에 왼손으로 시전합니다. 충전 첫 단계는 이동 속도 50%, 두 번째 원 충전 시작부터는 이동과 구르기를 막습니다. 두 번째 단계는 왼손을 앞으로, 오른손을 위로 올립니다. 놓으면 왼발을 고정한 채 오른발을 내디디며 오른손으로 시전합니다. 세 번째 원도 두 번째 단계 자세를 유지합니다.

확인 화면에서 Space 또는 마법 충전 버튼을 누르고 유지하면 충전·시전을 시험합니다. 게임은 기존 QWE 충전을 유지하며 키를 모두 떼거나, 충전 중 경기장 위에서 마우스 왼쪽 버튼을 놓으면 발사합니다. 우클릭은 계속 이동입니다. 확인 화면의 발사 구체는 자세 확인용이며 실제 게임은 선택한 주문 효과를 사용합니다. 게임 발사 시점은 준비 두 프레임이 지난 시점과 연결했습니다.

검증: test-pose-data.mjs의 유지·보간·JSON 검증 통과. 브라우저에서 좌표 입력, 앞 화면 관절 드래그와 되돌리기, 동작 전환을 확인했습니다.

## 친구와 1대1 대전

[오라클 서버에서 플레이](https://radio.magamiscom.ing/mage/)

시작 화면에서 **친구와 대전**을 선택합니다. 한 사람이 **방 만들기**를 누르고, 친구는 같은 사이트에서 6자리 방 코드를 입력해 **참가하기**를 누릅니다. **초대 링크 복사**로 방 코드가 미리 입력된 링크를 보낼 수도 있습니다. 두 사람이 마법을 고르고 **대전 준비**를 누르면 3초 뒤 시작합니다.

- Q·W·E 예약, 좌클릭 충전·발사, 우클릭 이동, Space 구르기를 사용합니다.
- 선택한 세 마법을 처음부터 숙련 1로 사용할 수 있습니다. 체력과 마력은 각각 100이며 몬스터·사냥·레벨업은 없습니다.
- 체력이 0이 되면 끝납니다. 10분이 지나면 남은 체력이 높은 쪽이 승리하고, 체력이 같으면 무승부입니다.
- 끝난 뒤 **재대결 준비**에서 다시 준비합니다. 마법 배치도 바꿀 수 있습니다.
- 온라인 대전은 일시정지하지 않습니다. 창을 벗어나면 이동과 충전을 취소하지만 경기는 계속됩니다.
- 한 사람이 나가거나 연결이 끊기면 경기를 종료합니다. 남은 사람은 같은 방에서 새 친구를 기다릴 수 있습니다. 진행 중인 경기 재접속은 지원하지 않습니다.
- **AI 연습**은 기존 AI 대결·정지 상대 연습과 사냥·성장 규칙을 유지합니다.

### 실행과 배포

Node.js 22 이상에서 다음을 실행합니다.

```sh
npm ci
npm start
```

기본 주소는 `http://localhost:8787`입니다. 서버가 게임 파일과 `/pvp` WebSocket을 함께 제공합니다. `HOST`, `PORT`, `MAX_ROOMS` 환경변수로 주소·포트·동시 방 수를 정합니다. 실행 기본값은 `0.0.0.0`, `8787`, 4개 방입니다. 방은 비어 있으면 즉시 정리하며, 대기 중 30분 동안 활동이 없으면 연결을 종료합니다.

GitHub Pages는 정적 파일만 제공하므로 대전 서버를 별도로 실행해야 합니다. `dist/pvp-config.mjs`가 공개 대전 서버 주소를 지정합니다. 로컬 접속은 같은 주소의 서버를 우선합니다. 서버 주소를 바꾸려면 방 화면의 **서버 연결 설정**을 펼칩니다. HTTPS 페이지에서는 `wss://` 주소가 필요합니다.

오라클 배포 파일은 `ops/ordinary-mage.service`, `ops/nginx-mage.conf`에 있습니다. 대전 프로세스는 전용 Node 실행 파일을 사용하며 시스템 Node를 바꾸지 않습니다. 기존 HTTPS 서버 블록에 `/mage/` 경로만 연결합니다. systemd 서비스는 메모리 512MB, CPU 0.5코어, 동시 4개 방으로 제한합니다.

### 전투 동기화와 검증

`dist/duel.mjs`는 기존 `LiveMagic`·충전·구르기·강제 이동·장벽 모듈을 재사용합니다. 서버가 초당 30회 전투를 계산하고, 허용된 입력과 상태를 양쪽에 전송합니다. 브라우저는 같은 입력을 재생해 효과를 표시한 뒤 서버의 위치·체력·상태로 보정합니다. 피해량·체력·위치는 클라이언트 요청에서 받지 않습니다. 투사체 시작 위치는 애니메이션 뼈 대신 캐릭터 앞 0.5m로 고정합니다. 마법 조합과 수치는 공유하지만 AI의 손 위치 기반 발사와는 이 차이가 있습니다.

- `npm run test:pvp`: 입력 검증, 이동 속도·충돌, 양쪽 구르기 무적, 마력·충전, 상태 보정, 실제 소켓 두 개의 방 생성·참가·준비·승패·재대결·접속 종료를 검사합니다.
- `node test-pvp-browser.mjs`: 독립 브라우저 세션 두 개에서 실제 UI로 이동·공격·승패·재대결·AI 복귀를 검사합니다. macOS에서는 설치된 Chrome을 사용하고, 다른 환경은 Playwright Chromium이 필요합니다.
- `PVP_TEST_URL=https://공개주소/ node test-pvp-browser.mjs`: 같은 브라우저 검사를 공개 서버에 실행합니다. 테스트용 방은 종료 시 정리됩니다.

입력은 서버 왕복 시간의 영향을 받습니다. 이동을 미리 확정하는 클라이언트 예측과 과거 시점 적중 보정, 계정·랭킹·자동 매칭은 포함하지 않습니다.

## 면소재지 전장

실제 전장에 식자재마트·공장·공원·면사무소 네 구역을 배치했습니다. 각 구역은 약 52×52m이며 건물과 소품은 가장자리 위주로 배치했습니다. 공원 중앙에는 팔각정이 있고, 외곽은 담과 펜스로 막았습니다. 바깥의 단층·2층 주택과 상가주택은 배경입니다. 건물 내부는 들어갈 수 없습니다.

카메라는 직교 투영이며 방위각 45도, 내려다보는 각도 약 35.264도입니다. 멀리 있는 물체도 같은 크기로 보이고 평행선은 모이지 않습니다. 게임의 **전체 지도 / 전투 시점** 버튼으로 시점을 바꿀 수 있습니다. WASD는 화면 방향을 따릅니다.

`npm start` 후 [3D 맵 보기](http://localhost:8787/town-map.html)에서 전체 배치와 각 구역을 확인할 수 있습니다. 드래그로 이동하고 휠로 확대합니다. **전투 시작**을 누르면 기존 게임으로 이동합니다.

- `dist/town-layout.mjs`: 건물·차량·나무·맵 경계와 공용 충돌 데이터.
- `dist/town-map.mjs`: 직접 만든 한국식 건물·팔각정·지면·간판과 Kenney 차량·거리 소품을 배치합니다. 정적 도형은 재질별로 합칩니다.
- `dist/korean-town-kit.mjs`: 직접 만든 식자재마트·면사무소·공장, 벽돌집·상가주택·기와집, 콘크리트 전봇대. 벽돌과 간판 텍스처도 코드로 생성합니다.
- `dist/town-assets.mjs`: Kenney GLB와 색상 텍스처를 불러옵니다. 원본·출처·CC0 라이선스는 `dist/assets/kenney/`에 있습니다. 주택 지붕 색상 변형과 지면 질감은 별도 제작했습니다.
- `dist/town-camera.mjs`: 게임과 미리보기에서 공유하는 직교 카메라.
- `node --test test-town-map.mjs test-keyboard-movement.mjs test-pvp.mjs test-screen-hit.mjs`: 투영, 이동 경로, 전투 마당, 차량 배치, 서버 충돌·전투 검사.
- `node test-town-browser.mjs`: 네 구역 렌더, 좁은 화면, WASD, 시전, 시점 전환을 검사하고 `output/town-map/`에 스크린샷을 저장합니다.

새 임무 진행 시스템은 포함하지 않습니다. 기존 몬스터 사냥과 마법 전투를 새 맵에서 사용합니다.

## 마법설계의 효과 편집

`skill-plan.html`에서 마법을 선택하고 **효과 만들기·조절**을 누르면 먼저 선택한 스킬의 실제 충전·발사·명중 과정을 보여줍니다. 조합, 좌/우 클릭, 1륜 충전 상태를 마법설계에서 그대로 넘기며 `mountAtlasPreview`의 게임 시전 코드를 재사용합니다. **미리볼 효과**에서 다른 효과를 직접 선택하면 Elemental Sandbox 원본 효과 6종을 편집합니다. 기존 샌드박스 저장값이나 초안이 있어도 처음에는 현재 스킬을 보여주며, **저장한 효과 불러오기**로 설계안을 다시 엽니다. 색·형태·타이밍·입자·발광을 조절하고 일시정지 중에도 결과를 확인할 수 있습니다. **펼친 상태로 멈추기**는 효과가 목표에 도착해 펼쳐지는 시점에 멈추며, **한 프레임 진행**은 1/60초씩 진행합니다. 현재 스킬 모드의 **시전 직후 멈추기**는 원래 충전 시간 이후 0.3초까지 게임 코드를 진행합니다. 현재 스킬 모드는 확인용이며 저장·기본값 복원·내보내기는 새 효과를 선택했을 때 활성화됩니다. 전달 속도나 입자 생성량 등 시간에 영향을 받는 설정은 다시 시전하면 전체 결과를 확인할 수 있습니다.

- 저장 키는 마법 조합별로 나뉘며, 기본 마법의 좌/우 손과 1륜 충전도 별도로 저장합니다.
- `mage-elemental-v1:saved:*`와 `mage-elemental-v1:draft:*`는 같은 브라우저·사이트의 localStorage에 저장됩니다. 편집기를 닫아도 초안을 복원합니다. 서버 동기화는 없으며 JSON 내보내기/불러오기로 옮깁니다.
- 현재는 **효과 설계 및 저장** 기능입니다. 게임의 전투 효과, 공격력, 충돌 판정에는 자동 적용하지 않습니다.
- `elemental-stage.mjs`는 원본 능력 코드와 후처리를 실행합니다. 편집기는 별도 iframe을 사용하여 게임의 Three.js 0.169 및 원본의 전역 설정과 분리합니다. 편집 중에는 기존 게임 미리보기를 해제하고 닫으면 다시 만듭니다.
- 원본 출처·고정 커밋·MIT 라이선스는 `dist/vendor/elemental/README.md`에 기록했습니다. 원본의 캐릭터·텍스처·외부 서비스를 가져오지 않았습니다.
- 검사: `node --test test-elemental-presets.mjs test-planner-spell.mjs`. 가져온 값의 범위 제한, 마법별 저장 분리, 초안 보존, 효과 전환 시 설정 초기화를 검사합니다.
